# GoCraft

![GoCraft Logo](assets/logo.png)

[English](README.md) | [中文](README_zh.md)

> [!IMPORTANT]
> **项目状态：Alpha**。GoCraft 是一个使用 Go 语言与原生 WebGPU 编写的高性能体素引擎与生存沙盒实验项目。它具备权威多人联机架构、确定性程序化地形生成、生存进度推进、容器处理以及数据驱动实体系统。

**GoCraft** 致力于在 Go 语言环境下探索清晰的工程架构、程序化无限地形生成、轻量级网络协议以及底层图形渲染优化。

## 特性

- **程序化世界与经典生物群系**：
  - 连续 6 区域气候模型：平原（Plains）、橡木/白桦混合森林（Forest）、沙漠（Desert）、云杉针叶林（Taiga）、山地/极端山丘（Extreme Hills）、雪原（Snowy Plains）、海洋、冻洋与沙滩/雪滩。
  - 确定性 900 格尺度等高线河流雕刻系统与冻河，河床自动生成砂砾与沙子。
  - 草地、树叶、水体色调以及距离雾效的平滑双线性过渡。
  - 基于坡度的岩石裸露计算、连续地下洞穴网络以及基于世界坐标的确定性树木与花草生成。
- **丰富的生存玩法系统**：
  - 完整的生存背包与配方书系统，支持搜索过滤、最大化合成以及木材变体自动替代。
  - 集中式挖掘数据配置，严格区分工具等级与采集权限，工具随使用产生耐久度磨损。
  - 持久化 27 格箱子与燃烧冶炼熔炉，具备权威服务端交互会话与防竞态同步。
  - 玩家生命值（20 HP）、水下氧气（15 秒）、掉落/岩浆/火焰/窒息/虚空伤害、死亡掉落与安全出生点锚定。
- **数据驱动的实体与生物**：
  - 基于 JSON 配置的模型部件、碰撞包围盒、关节动画步态、无声 AI 行为（漫游、停歇、受惊逃跑）与战斗判定。
  - 内置可视化模型工坊（`./gocraft.exe -mob-preview`），支持热重载 JSON 模型与动画配置。
- **现代像素风界面与设置**：
  - 统一深色像素风格菜单、容器交互面板、合成列表与快捷栏 HUD。
  - 持久化配置文件（`settings.json`），原生支持 16:9、16:10、21:9 和 4:3 宽高比，带平滑鼠标灵敏度调节。
- **权威多人联机与安全持久化**：
  - 专用 TCP 服务端/客户端架构，具备实体插值、事务校验容器交互以及管理命令。
  - 崩溃免疫的原子文件保存机制（`.tmp` 写入 + 重命名替换），确保区块数据、容器状态与玩家存档在异常断电时不损坏。
- **高级光照与着色器**：
  - 天空光与方块光传播算法、环境光遮蔽（AO）、日夜循环以及自定义 WGSL Cutout 与雾效着色器。

## 快速开始

### 前置要求

- [Go](https://go.dev/dl/) 1.25 或更高版本。
- 原生客户端目前需要 Windows 和支持 Vulkan 的显卡驱动。Raylib 及其 C 编译器要求已移除。

### 运行游戏

1. **克隆仓库：**
   ```bash
   git clone https://github.com/P0T47O/gocraft.git
   cd gocraft
   ```

2. **运行客户端（单人模式/默认）：**
   ```bash
   go run .
   ```

   **关于材质包**: 
   本仓库不包含有版权的游戏商业资源，默认使用程序生成的黑紫棋盘格占位符运行。如需使用标准材质包：
   1. 在游戏根目录下找到或新建 `textures/` 文件夹。
   2. 使用任意标准的 Minecraft Java 版（推荐 1.20+）材质包 `.zip` 或游戏客户端 `.jar`。
   3. 解压并进入 `assets/minecraft/textures/` 目录。
   4. 将里面的内容（`block`、`item`、`gui` 等文件夹）复制到本地 `textures/` 文件夹中。
   
   *（项目的 `.gitignore` 已配置忽略 `textures/` 与 `minecraft/` 文件夹，避免提交版权素材）。*

### 多人联机

启动专用服务端：
```bash
go run . -server
```

以特定用户名加入游戏（客户端）：
```bash
go run . -name PlayerName
```

## 核心系统与架构详解

### 生存背包与合成系统

按 **E** 键打开背包与配方书。**全部配方**（All recipes）显示所需材料及工作台要求；**可合成**（Ready to craft）仅过滤当前材料充足的项目。选定配方后点击 **Craft** 制作单组或 **Craft max** 一键批量制作（单次最多 64 组）。背包空间不足时将自动取消制作并不消耗原料。

- **左键槽位**：拿起、放下、堆叠合并或交换物品。
- **右键槽位**：取出一半（向上取整）或单个放置。
- **Shift + 左键**：在背包与快捷栏之间快速穿梭转移。
- **鼠标悬停**：查看物品名称、堆叠数量及工具剩余耐久。
- **E / ESC / X**：安全关闭界面，光标抓取的物品会自动放回背包。

右键放置在地面的工作台可开启 3x3 高级合成。涉及木材的配方（如木棍、木工具）会自动适配背包内现有的任意木材变体。

### 物品定义、耐久度与挖掘规则

- `item_registry.go` 集中管理物品定义（堆叠上限、最大耐久、方块放置映射）。`ItemStack` 结构体贯穿背包、光标、容器与地面掉落物。
- 工具独立不可堆叠。最大耐久：木质 (59)、石质 (131)、铁质 (250)、钻石 (1561)、金质 (32)。生存模式下每破坏一个硬度大于 0 的方块消耗 1 点耐久；秒碎方块与创造模式不消耗耐久；耗尽后工具损毁。
- 挖掘硬度与采集权限在 `mining_data.go` 集中配置。石头类方块必须使用达标镐子破坏才会掉落物品；徒手挖掘仅能正常采集木头和泥土。玻璃、冰、树叶与高草丛目前无普通掉落。

### 容器系统：箱子与熔炉

- **箱子**：在工作台使用 8 个相同木板合成 27 格储物箱。右键打开，Shift+右键可贴着已有箱子放置方块。Shift+左键可在箱子与背包间快速转移整组物品。
- **熔炉**：使用 8 个圆石合成。可将铁/金矿石冶炼为锭、沙子烧制成玻璃、圆石烧制为石头、生猪排烹饪为熟猪排。
  - 冶炼耗时：每个物品固定 10 秒。
  - 燃料效率：煤炭（8 个物品）、煤炭块（80 个物品）、木材/木板（1.5 个物品）、木棍（0.5 个物品）。
  - 只要区块处于加载状态，关闭熔炉界面燃烧与冶炼进度依然正常推进。
  - 破坏箱子或熔炉会将内部所有存货及燃料如数散落至地面。
- 容器状态统一存储于 `containers.json`，并通过带事务版本控制的会话与客户端同步。

### 角色运动、生命值与重生

- 生存模式下玩家拥有 20 点生命值（10 颗心）与 15 秒水下呼吸时间。
- 服务端统一结算跌落伤害（落水可免伤）、溺水伤害、岩浆与火焰灼烧、方块窒息以及掉入虚空伤害。
- 脱离危险后，角色每 10 秒缓慢回复 1 点生命值。
- 死亡时背包与光标物品原地散落，点击 **Respawn** 会在保存的出生点附近满血重生并加载周围地形。若地面悬空无立足点，系统会自动生成安全的圆石降落台。

### 数据驱动生物与实体

- 实体模型与行为由 `content/` 目录下的 JSON 文件驱动：
  - `content/entities/pig.json`：基础生命值、移速、碰撞体尺寸、游荡/逃跑时长与生成上限。
  - `content/models/pig.json`：父子级节旋转轴、部件立方体长宽深与 16px/格纹理 UV 贴图映射。
  - `content/animations/quadruped.json`：四足步态行走相位与摆幅。
- 启动 `./gocraft.exe -mob-preview` 可进入专属模型检视工坊：
  - 按键 **1–5**：切换动作（Idle 站立、Walk 行走、Flee 逃跑、Hurt 受击、Death 死亡倒地）。
  - **A / D**：旋转模型视角；**B**：切换碰撞线框显示；**R**：免重启热重载 JSON 配置文件。
- 猪会在玩家周围的草地表面自然生成（单区域上限 8 只，全局 64 只）。受击会触发受惊狂奔 AI；死亡掉落 1-3 块生猪排。

### 经典生物群系、河流雕刻与环境雾效

- `generation_biomes.go` 实现了平滑连续的 6 区域气候模型：
  - 平缓起伏的平原与橡木/白桦混合林。
  - 连绵沙丘、砂岩地底与仙人掌/枯死灌木装点的干燥沙漠。
  - 云杉林立的针叶林与冰雪覆盖的极寒雪原。
  - 山脊陡峭、高落差、根据山体坡度自然裸露岩石的山地（Extreme Hills）。
- **等高线河流雕刻**：
  - 采用 900 格尺度扭曲噪声等高线，在原本平滑的地形上雕刻出低于海平面（Y=61）的河道（河床深至 Y=57）。
  - 温带河道自动铺垫砂砾与泥土河床，沙漠河道铺垫沙质河床，寒冷生物群系河面自动结冰。
- 视距环境雾效在不同生物群系间平滑插值过渡颜色与浓度。

### 存档系统与原子写入保障

- 所有存档持久化操作（`save_file.go`）均采用原子写入机制：数据先完整落盘至 `.tmp` 临时文件，再通过系统级原子操作 `os.Rename` 替换目标文件。
- 崩溃安全：游戏突发崩溃或强行终止进程绝不会产生 0 字节截断的损坏存档。
- 区块体素与光照数据使用高压缩比、高性能的 `zstd` 进行块压缩。
- 自动向下兼容：实体存档（版本 9）与玩家存档（版本 2）在加载旧版本数据时会自动迁移格式。

## 验证与自动化测试

运行全套单元与集成测试：
```bash
go test -count=1 ./...
```

运行独立的地形生成测试框架（无需图形依赖）：
```bash
go run ./tests/generation
```

导出 CPU 地形分析诊断图（高程山体阴影图、坡度图、地表覆盖分布）：
```powershell
$env:GOCRAFT_REVIEW_DIR = 'work/generation-review'
go test -run TestGenerationReviewMaps -v .
Remove-Item Env:GOCRAFT_REVIEW_DIR
```

运行图形渲染预览测试（截图自动输出至 `work/` 目录）：
```powershell
# 背包界面渲染预览
$env:GOCRAFT_INVENTORY_PREVIEW='1'; go test -run '^TestInventoryPreview$' -count=1 .

# 箱子与熔炉容器界面渲染预览
$env:GOCRAFT_CONTAINER_PREVIEW='1'; go test -run '^TestContainerPreview$' -count=1 .

# 生物模型渲染与骨骼动画预览
$env:GOCRAFT_MOB_PREVIEW='1'; go test -run '^TestMobRenderPreview$' -count=1 .
```
